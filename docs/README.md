# Документи

Правила для агента й для кожного, хто міняє сайт, — у [AGENTS.md](../AGENTS.md) в корені.
`CLAUDE.md` лише вказує на нього.

## Що ще відкрите

- [plan.md](plan.md) — що таке сайт, скільки матеріалу в одній статті, карта статей за Мерзляком
  і **порядок**, у якому робиться відкрита робота.
- [work/pages.md](work/pages.md) — відкриті завдання по уроках і меню. Іншого місця для відкритої
  роботи немає.

## Як усе влаштовано і який файл що вирішує

Відкрий той, чого стосується зміна, — до пропозиції, а не тільки до коду.

- [Сайт](internals/site.md) — теки й адреси, спільні `assets/`, тема, локальний перегляд, деплой
- [Урок](internals/lesson-page.md) — стандарт уроку: покроковий розклад, перемикання, будова
  сторінки, компоненти `assets/lesson.css`
- [Кольори](internals/colours.md) — позначки `--mark-1…4`, реєстр понять між уроками, червоний
  `--alert`
- [Меню](internals/menu.md) — картки, теги, фільтр і групування, зовнішні сайти
