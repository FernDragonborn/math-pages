# Математика по темах

Уроки й шпаргалки з математики українською, де механізм видно, а не тільки правило: перемикаєш
варіанти й дивишся, як вираз розкладається крок за кроком.

**Сайт:** https://math.45-145-224-180.sslip.io/

Теми: ступені й логарифми, арифметика, дроби, рівняння, геометрія. У меню кожен урок має теги
(клас, розділ, формат), за ними можна фільтрувати й групувати; поруч стоять посилання на кілька
корисних зовнішніх сайтів.

## Запустити в себе

Збирати нічого не треба: це статичні HTML-сторінки.

```sh
python -m http.server 8765
```

і відкрити http://localhost:8765/ (через `file://` не працює: шляхи до `assets/` абсолютні).

## Для тих, хто змінює сайт

Правила — в [AGENTS.md](AGENTS.md), мапа документів — у [docs/README.md](docs/README.md).
Оновлення сервера — `./deploy.sh` (потрібен SSH-доступ).
