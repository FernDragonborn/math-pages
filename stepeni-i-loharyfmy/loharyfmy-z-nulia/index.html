Логарифми з нуля

Посібник для 11 класу. Потрібні тільки степені з 8 класу — їх ми теж згадаємо. Все можна натискати.

Відповідь на питання «у який степінь?» — це і є логарифм. Решта посібника — про те, як цю відповідь знаходити.

    §1

    Степені: коротко згадуємо

    Степінь — це скорочений запис множення однакових чисел:

    \[a^n = \underbrace{a\cdot a\cdot \ldots \cdot a}_{n}\]

    Тут \(a\) — основа (що множимо), \(n\) — показник (скільки разів). Наприклад, \(2^3 = 2\cdot2\cdot2 = 8\).

    Подивись на «драбину» степенів. Обери основу:

    Кожен крок униз — показник меншає на 1, а число ділиться на основу. Дійшли до \(a^1 = a\), поділили ще раз — отримали \(a^0 = 1\). Ще раз — \(a^{-1} = \frac1a\). Тож \(a^0 = 1\) (для \(a \ne 0\), бо на нуль ділити не можна) і від'ємні показники — не правила «з повітря», а просто продовження драбини.

    Три правила, які знадобляться в §5

    • \(a^m \cdot a^n = a^{m+n}\)
      Чому: спочатку \(m\) множників, потім ще \(n\) — разом \(m+n\). Приклад: \(2^2\cdot 2^3 = (2\cdot2)(2\cdot2\cdot2) = 2^5\).
    • \(\dfrac{a^m}{a^n} = a^{m-n}\)
      Чому: \(n\) множників у дробі скорочуються. \(\frac{2^5}{2^2} = 2^3\).
    • \(\left(a^m\right)^n = a^{m\cdot n}\)
      Чому: \(n\) разів беремо по \(m\) множників. \(\left(2^2\right)^3 = 2^2\cdot2^2\cdot2^2 = 2^6\).

    В 11 класі показник може бути й дробом: \(4^{\frac12} = \sqrt4 = 2\), бо \(\left(4^{\frac12}\right)^2 = 4^1\) — за третім правилом. Поки що досить знати, що таке буває.

    §2

    Що таке логарифм

    Логарифм відповідає на питання: у який степінь треба піднести основу, щоб отримати число?

    \[\log_{\class{ka}{a}} \class{kb}{b} = \class{kc}{c} \quad\Longleftrightarrow\quad \class{ka}{a}^{\class{kc}{c}} = \class{kb}{b}\]
    a — основаb — число, з якого беремо логарифмc — логарифм, тобто показник

    Читається «логарифм \(b\) за основою \(a\)». Головне: логарифм — це показник степеня. Ось та сама драбина, прочитана справа наліво:

    Переклади з мови степенів на мову логарифмів

    Спробуй сам, потім натисни на картку, щоб перевірити.

    Що корисно знати напам'ять

    • \(\log_a 1 = 0\)
      Бо \(a^0 = 1\) для будь-якої допустимої основи.
    • \(\log_a a = 1\)
      Бо \(a^1 = a\).
    • \(\log_a a^k = k\)
      Це головний інструмент для обчислень (див. §4): якщо число вже записане як степінь основи, логарифм — це просто показник.
    • \(a^{\log_a b} = b\) — основна логарифмічна тотожність
      \(\log_a b\) — це саме той показник, у який треба піднести \(a\), щоб вийшло \(b\). Підносимо — отримуємо \(b\). Наприклад, \(2^{\log_2 7} = 7\).

    Дві основи мають власні позначення: \(\lg b = \log_{10} b\) (десятковий логарифм) і \(\ln b = \log_e b\) (натуральний, \(e \approx 2{,}718\) — це спеціальне число, пізніше побачиш, звідки воно). На калькуляторі зазвичай є саме кнопки lg (або log) і ln.

    §3

    Коли логарифм існує

    \(\log_a b\) має сенс, тільки якщо

    \[a \gt 0,\qquad a \ne 1,\qquad b \gt 0\]

    Ці умови не треба зубрити — кожна має просту причину. Відкрий і подивись:

    А що, якщо основа \(a = 1\)?

    \(1^c = 1\) при будь-якому \(c\). На питання «у який степінь піднести 1, щоб вийшло 5?» відповіді немає взагалі, а на «…щоб вийшло 1?» — безліч відповідей. Тому з основою 1 логарифм не визначають.

    А що, якщо основа від'ємна або нуль?

    \((-2)^2 = 4\), \((-2)^3 = -8\) — знак скаче, а \((-2)^{\frac12} = \sqrt{-2}\) серед дійсних чисел не існує. З нулем теж погано: \(0^c = 0\) для будь-якого додатного \(c\). Тому основа — тільки додатна.

    А що, якщо число \(b \le 0\)?

    Додатна основа в будь-якому степені дає додатне число: навіть \(2^{-10} = \frac{1}{1024}\) — маленьке, але більше за нуль. Отже, \(2^c\) ніколи не дорівнює \(-8\) чи \(0\), і \(\log_2(-8)\), \(\log_2 0\) не існують.

    Звідси береться ОДЗ у рівняннях: все, що стоїть під логарифмом, має бути більше за нуль. Повернемося до цього в §7.

    §4

    Як обчислити логарифм без калькулятора

    1. Запиши число як степінь основи. Якщо не виходить — запиши і основу, і число як степені одного й того самого числа.
    2. Користуйся тим, що \(\log_a a^k = k\), або прирівняй показники.

    Так рахуються «гарні» логарифми, які дають цілу відповідь або простий дріб. Наприклад, \(\log_2 7\) так не порахуєш: 7 не є зручним степенем двійки. Для таких є калькулятор (§5).

    Розв'язки відкриваються по кроку. Спробуй вгадати наступний крок, перш ніж натиснути.

    Приклад 1. \(\log_3 81\)

    1. \(81 = 3\cdot3\cdot3\cdot3 = 3^4\)
      Ділимо 81 на 3, поки не вийде 1: 81 → 27 → 9 → 3 → 1. Чотири ділення.
    2. \(\log_3 81 = \log_3 3^4 = 4\)
      Логарифм степеня основи — це показник.

    Приклад 2. \(\log_2 \frac{1}{16}\)

    1. \(\frac{1}{16} = \frac{1}{2^4} = 2^{-4}\)
      Від'ємний показник: \(a^{-n} = \frac{1}{a^n}\) (§1, низ драбини).
    2. \(\log_2 2^{-4} = -4\)
      Відповідь від'ємна — і це нормально. Від'ємним не може бути число під логарифмом, а сам логарифм — може.

    Приклад 3. \(\log_4 8\)

    1. \(4 = 2^2,\quad 8 = 2^3\)
      8 не є цілим степенем 4, зате обидва числа — степені двійки.
    2. Нехай \(\log_4 8 = c\). Тоді \(4^c = 8\), тобто \(\left(2^2\right)^c = 2^3\).
      Означення логарифма (§2).
    3. \(2^{2c} = 2^3\)
      Степінь степеня: показники множимо.
    4. \(2c = 3 \;\Rightarrow\; c = \frac32\)
      Основи однакові — значить, рівні й показники.

    Приклад 4. \(\log_{\frac12} 8\)

    1. \(\frac12 = 2^{-1},\quad 8 = 2^3\)
      Знову все через двійку.
    2. \(\left(2^{-1}\right)^c = 2^3 \;\Rightarrow\; 2^{-c} = 2^3\)
      Степінь степеня.
    3. \(-c = 3 \;\Rightarrow\; c = -3\)
      Перевірка: \(\left(\frac12\right)^{-3} = 2^3 = 8\). ✓
    §5

    Властивості логарифмів

    Головна ідея: логарифм перетворює множення на додавання. Це прямо випливає з правила \(a^m\cdot a^n = a^{m+n}\) з §1. Перевір сам — обери два числа:

    Правила

    Працюють, коли \(x \gt 0\) і \(y \gt 0\). У третьому правилі додатним має бути саме \(x\): наприклад, \(\log_2 (-4)^2\) існує (це \(\log_2 16 = 4\)), а \(2\log_2(-4)\) — ні.

    • \(\log_a(xy) = \log_a x + \log_a y\)
      Чому так
      Будь-яке додатне число можна записати як степінь основи: \(x = a^m\), \(y = a^n\), де \(m = \log_a x\), \(n = \log_a y\) (за основною тотожністю). Тоді \(xy = a^m\cdot a^n = a^{m+n}\), отже \(\log_a(xy) = m + n\).
    • \(\log_a \dfrac{x}{y} = \log_a x - \log_a y\)
      Чому так
      Так само: \(\frac{x}{y} = \frac{a^m}{a^n} = a^{m-n}\), отже логарифм частки дорівнює \(m - n\).
    • \(\log_a x^k = k\cdot\log_a x\)
      Чому так
      \(x^k = \left(a^m\right)^k = a^{mk}\), отже \(\log_a x^k = mk = k\log_a x\).
    • \(\log_a b = \dfrac{\log_c b}{\log_c a}\) — перехід до іншої основи
      Чому так і навіщо
      Нехай \(\log_a b = t\), тобто \(a^t = b\). Візьмемо логарифм за будь-якою допустимою основою \(c\) (\(c \gt 0,\ c \ne 1\)) від обох частин: \(\log_c a^t = \log_c b\), за третім правилом \(t\log_c a = \log_c b\), звідки \(t = \frac{\log_c b}{\log_c a}\).
      Навіщо: на калькуляторі є лише lg і ln, тому \(\log_2 7 = \frac{\lg 7}{\lg 2} \approx 2{,}807\).

    Типові пастки

    \(\log_a(x + y) \ne \log_a x + \log_a y\). Перевір: \(\log_2(4 + 4) = \log_2 8 = 3\), а \(\log_2 4 + \log_2 4 = 4\).

    \(\dfrac{\log_a x}{\log_a y} \ne \log_a \dfrac{x}{y}\). Ліворуч — перехід до основи \(y\): це \(\log_y x\).

    \(\left(\log_a x\right)^2 \ne 2\log_a x\). Правило про показник працює лише тоді, коли в степінь піднесене число під логарифмом, а не сам логарифм.

    Приклад 1. \(\log_6 4 + \log_6 9\)

    1. \(\log_6 4 + \log_6 9 = \log_6 (4\cdot 9) = \log_6 36\)
      Сума логарифмів з однаковою основою — логарифм добутку. Окремо \(\log_6 4\) цілим числом не порахуєш, а разом — легко.
    2. \(\log_6 36 = \log_6 6^2 = 2\)

    Приклад 2. \(2\log_3 6 - \log_3 4\)

    1. \(2\log_3 6 = \log_3 6^2 = \log_3 36\)
      Множник перед логарифмом «заходить» у показник (третє правило навпаки).
    2. \(\log_3 36 - \log_3 4 = \log_3 \frac{36}{4} = \log_3 9\)
      Різниця логарифмів — логарифм частки.
    3. \(\log_3 9 = \log_3 3^2 = 2\)
    §6

    Графік \(y = \log_a x\)

    Обери основу і подивись, як змінюється графік:

    • Існує лише при \(x \gt 0\).
      Графік весь праворуч від осі \(Oy\) і ніколи її не торкається — це умова \(b \gt 0\) з §3.
    • Завжди проходить через точки \((1;\,0)\) і \((a;\,1)\).
      Бо \(\log_a 1 = 0\) і \(\log_a a = 1\) (§2).
    • Якщо \(a \gt 1\) — функція зростає, якщо \(0 \lt a \lt 1\) — спадає.
      Це знадобиться для нерівностей у §7.
    • Це дзеркальне відображення графіка \(y = a^x\) відносно прямої \(y = x\).
      Бо логарифм «скасовує» піднесення в степінь: точка \((2;\,4)\) на графіку \(y = 2^x\) перетворюється на \((4;\,2)\) на графіку \(y = \log_2 x\). Увімкни галочку вище — побачиш.
    §7

    Рівняння і нерівності

    Майже всі шкільні логарифмічні рівняння розв'язуються за одним планом:

    1. ОДЗ: усе, що стоїть під логарифмами, має бути \(\gt 0\) (§3).
    2. Зведи кожну частину до одного логарифма (властивості з §5).
    3. Прибери логарифм: \(\log_a f(x) = c \Rightarrow f(x) = a^c\) (означення, §2) або \(\log_a f(x) = \log_a g(x) \Rightarrow f(x) = g(x)\).
    4. Розв'яжи звичайне лінійне чи квадратне рівняння — це 8 клас.
    5. Перевір корені за ОДЗ і викинь зайві.

    Приклад 1. \(\log_3(x - 1) = 2\)

    1. ОДЗ: \(x - 1 \gt 0 \Rightarrow x \gt 1\)
    2. \(x - 1 = 3^2 = 9\)
      За означенням: логарифм дорівнює 2, отже \(3^2\) дає те, що під логарифмом.
    3. \(x = 10\). Перевірка: \(10 \gt 1\) ✓
      Відповідь: \(x = 10\).

    Приклад 2. \(\log_2 x + \log_2 (x - 2) = 3\)

    1. ОДЗ: \(x \gt 0\) і \(x - 2 \gt 0\), тобто \(x \gt 2\)
    2. \(\log_2\big(x(x - 2)\big) = 3\)
      Сума логарифмів — логарифм добутку (§5).
    3. \(x(x - 2) = 2^3 = 8 \;\Rightarrow\; x^2 - 2x - 8 = 0\)
    4. \(x_1 = 4,\; x_2 = -2\)
      За теоремою Вієта: \(x_1 + x_2 = 2\), \(x_1 x_2 = -8\). Можна й через дискримінант: \(D = 4 + 32 = 36\).
    5. \(-2\) не підходить: \(-2 \gt 2\) неправда.
      Відповідь: \(x = 4\). Якби ми пропустили ОДЗ, записали б зайвий корінь — це найчастіша помилка.

    Приклад 3. \(\log_5(2x + 1) = \log_5(x + 4)\)

    1. ОДЗ: \(2x + 1 \gt 0\) і \(x + 4 \gt 0\), тобто \(x \gt -\frac12\)
    2. \(2x + 1 = x + 4\)
      Основи однакові, логарифми рівні — значить, рівні й числа під ними (функція монотонна, §6).
    3. \(x = 3\). Перевірка: \(3 \gt -\frac12\) ✓

    Нерівності

    Тут усе вирішує графік з §6:

    Якщо \(a \gt 1\) — знак нерівності зберігається.
    Якщо \(0 \lt a \lt 1\) — знак змінюється на протилежний.
    І не забувай ОДЗ.

    Приклад 4. \(\log_2 x \gt 3\)

    1. \(3 = \log_2 8\), тож \(\log_2 x \gt \log_2 8\)
      Записуємо праву частину як логарифм з тією самою основою.
    2. \(x \gt 8\)
      \(2 \gt 1\), функція зростає — знак зберігається. ОДЗ \(x \gt 0\) виконується автоматично.

    Приклад 5. \(\log_{\frac12} x \gt 3\)

    1. \(3 = \log_{\frac12} \frac18\), тож \(\log_{\frac12} x \gt \log_{\frac12} \frac18\)
      Бо \(\left(\frac12\right)^3 = \frac18\).
    2. \(x \lt \frac18\)
      \(\frac12 \lt 1\), функція спадає — знак змінюється.
    3. З урахуванням ОДЗ: \(0 \lt x \lt \frac18\)
    §8

      Шпаргалка

      \(\log_a b = c \iff a^c = b\)
      Логарифм — це показник степеня.
      \(a \gt 0,\; a \ne 1,\; b \gt 0\)
      Коли логарифм існує. Звідси ОДЗ.
      \(\log_a 1 = 0,\quad \log_a a = 1\)
      \(\log_a a^k = k,\quad a^{\log_a b} = b\)
      \(\log_a(xy) = \log_a x + \log_a y\)
      \(\log_a \frac{x}{y} = \log_a x - \log_a y\)
      \(\log_a x^k = k\log_a x\)
      \(\log_a b = \dfrac{\log_c b}{\log_c a}\)
      Перехід до іншої основи. \(\lg = \log_{10}\), \(\ln = \log_e\).
      \(y = \log_a x\): через \((1;\,0)\); \(a \gt 1\) — зростає, \(0 \lt a \lt 1\) — спадає
      Рівняння: ОДЗ → один логарифм → прибрати логарифм → розв'язати → перевірити за ОДЗ
      Нерівності: \(a \gt 1\) — знак той самий, \(0 \lt a \lt 1\) — знак міняється
      Прогрес у тестах і тренажері зберігається на цьому пристрої.
