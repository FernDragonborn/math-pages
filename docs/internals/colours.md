# Кольори

> Що означає колір на сайті. Токени — в `assets/site.css`, світла й темна версії поруч.

## Позначки

Кольорами позначають поняття, які розбирає урок, щоб розрізняти кілька одночасно: у логарифмах їх
три — основа й два різні значення. Одне поняття — одна позначка на всю сторінку; на сторінці її
називають один раз.

| Токен | Колір |
|---|---|
| `--mark-1` | синій |
| `--mark-2` | фіолетовий |
| `--mark-3` | зелений |
| `--mark-4` | помаранчевий |

До кожної є `--mark-N-wash` для фону. Нове поняття бере вільну позначку по черзі.

## Реєстр: між уроками колір зберігається

Поняття, що вже має позначку, бере ту саму на кожній сторінці. Нове поняття — новий рядок тут.

| Поняття | Позначка | Де |
|---|---|---|
| основа ступеня / логарифма | `--mark-1` | Що таке ступінь, Ступені під капотом, Логарифми |
| показник (і логарифм як показник), крок ×a / ÷a | `--mark-2` | Що таке ступінь, Ступені під капотом, Логарифми |
| значення / результат (b у логарифмі, що вийшло) | `--mark-3` | Що таке ступінь, Ступені під капотом, Логарифми |
| друга порція того самого, поруч із першою | `--mark-4` | Що таке ступінь (aᵐ·aⁿ), Логарифми (графік показникової функції) |
| дія над обома частинами рівняння | `--mark-2` | Терези, Перетворення |
| дроби в прикладі (перший, другий, третій) | `--mark-1`, `--mark-3`, `--mark-2` | Спільний знаменник |
| додатковий множник («бракує»), пунктирна рамка | `--mark-4` | Спільний знаменник |
| рівні відрізки, кути й побудови на малюнку | `--mark-2` | Трапеція |

## Червоний — не позначка

`--alert` (`--alert-wash`, `--alert-line`) — тільки окремі виноски «часті помилки» / «увага» і стан
«помилка»: неправильна відповідь, «не підходить», «нуль зник», кнопка-пастка `× 0`, мітка «часто в
задачах». Усередині формул, розкладів, номерів розділів, підписів і рукописних приміток червоного
немає, навіть якщо це головне поняття теми.

## Інші кольори з роллю

- Синій `--pen` — ще й колір інтерфейсу: посилання, головні кнопки, вибраний варіант, номери
  розділів.
- Зелений, крім позначки, означає «правильно» в станах перевірки.
- Кольори тем у меню (`--t1…4`) — тільки для розрізнення розділів меню, не позначки.
