Корінь n-го ступеня

Корінь — це питання навпаки: яке число треба піднести до n-го ступеня, щоб вийшло a?

Щоб зрозуміти цю тему, треба знати: Що таке ступінь Властивості ступеня квадратний корінь, 8 клас

1Шукаємо x, у якого xn = a

Коренем n-го ступеня з числа a називають число, n-й ступінь якого дорівнює a. Обери n і a — і перевіримо кандидатів.

ступінь n
число a

2Властивості коренів

Кожна властивість — наслідок властивостей ступеня. Обери властивість і крути приклади: обидві частини щоразу дають те саме.

3Пастки

Звідси: корінь не «розходиться» по доданках, корінь парного ступеня завжди невідʼємний, а з відʼємного числа серед дійсних його немає.

4Перевір себе

Спершу знайди сам, потім відкривай.

3√125
= 5, бо 5·5·5 = 125.
4√81
= 3. Рівняння x4 = 81 має два корені, ±3, а знак 4√ — це невідʼємний з них.
3√(−27)
= −3, бо (−3)·(−3)·(−3) = −27. Непарний ступінь — корінь з відʼємного існує.
4√(−16)
Серед дійсних чисел не існує: будь-яке число в четвертому ступені невідʼємне.
√(4·25)
= √4·√25 = 2·5 = 10.
√((−7)2)
= √49 = 7 = |−7|, а не −7.
Корінь n-го ступеня з a — число, n-й ступінь якого дорівнює a.

n непарне: корінь є з будь-якого числа, і він один — n√a.
n парне: при a > 0 коренів два, протилежних; n√a — невідʼємний з них (арифметичний корінь). При a < 0 — жодного.

n√(ab) = n√a · n√b, n√(a/b) = n√a / n√b, (n√a)k = n√(ak), k√(n√a) = nk√a (a, b ≥ 0, b ≠ 0 у частці).

Далі — «Дробовий показник»: a1/n = n√a.
