Системи лінійних рівнянь: підстановка й додавання

Два рівняння, два невідомі — і треба знайти пару чисел, яка підходить в обидва. Два способи приводять систему до одного рівняння з одним невідомим.

Щоб зрозуміти цю тему, треба знати: Лінійне рівняння з однією змінною Тотожні перетворення Як працює графік функції

1Розвʼязок — пара, що підходить в обидва

Система — кілька рівнянь, які мають виконуватися одночасно. Тут два невідомі: x і y.

Розвʼязок системи — пара (x; y), яка робить правильними обидва рівняння. Одного не досить.

x + y = 5x − y = 1

Обери пару й перевір:

2Два способи — один розвʼязок

Обери систему й спосіб. Перемкни спосіб — розклад піде інакше, а відповідь та сама.

3Де помиляються

Звідси правило: множиш рівняння — множ обидві його частини. Відповідь системи — пара (x; y), першим завжди x. І перевіряй пару в обох рівняннях.

4Навіщо це: дві прямі на площині

Кожне рівняння з двома змінними — це пряма: усі пари, що йому підходять. Розвʼязок системи — спільна точка обох прямих. Тут система, яку ти вибрав вище.

Прямі перетинаються — один розвʼязок. Паралельні — жодного. Збігаються — безліч.

5Перевір себе

Спершу розвʼяжи сам. Потім відкривай.

x + y = 10, x − y = 4
Додаємо: 2x = 14, x = 7; тоді y = 10 − 7 = 3. Відповідь: (7; 3).
y = 2x, x + y = 9
Підставляємо: x + 2x = 9, x = 3, y = 6. Відповідь: (3; 6).
3x − y = 5, x + 2y = 4
З першого y = 3x − 5; x + 2(3x − 5) = 4, 7x = 14, x = 2, y = 1. Відповідь: (2; 1).
x − y = 1, 2x − 2y = 5
Множимо перше на −2 і додаємо: 0 = 3 — неправда. Розвʼязків немає: прямі паралельні.
2x + 3y = 8, 4x + 6y = 16
Друге — це перше, помножене на 2. Множимо перше на −2 і додаємо: 0 = 0. Розвʼязків безліч: прямі збігаються.
Коротко:
Розвʼязок системи — пара (x; y), що підходить в обидва рівняння.
Підстановка: вирази одне невідоме з одного рівняння й підстав в інше.
Додавання: помнож рівняння так, щоб коефіцієнти при одному невідомому стали протилежними, і додай.
Вийшло 0 = 0 — розвʼязків безліч; 0 = число — розвʼязків немає.

Розвʼязувати рівняння з одним невідомим — «Лінійне рівняння з однією змінною»; системи на графіку — у шпаргалці «Графіки функцій».
