Лінійне рівняння з однією змінною

Будь-яке таке рівняння кількома кроками зводиться до вигляду ax = b. А з нього одразу видно, скільки коренів: один, жодного чи безліч.

Щоб зрозуміти цю тему, треба знати: Терези: роби з обома частинами однакове Тотожні перетворення дії з відʼємними числами, 6 клас

1Вигляд ax = b

Лінійне рівняння з однією змінною — рівняння, яке зводиться до вигляду ax = b, де a і b — числа, а x — невідоме.

Синє на цій сторінці — невідоме x, фіолетове — дія над обома частинами, зелене — корінь.

Скільки коренів, вирішує a. Зміни a і b і подивись:

2Від будь-якого вигляду до ax = b

Обери рівняння й розвʼязуй його по кроку. Кожен рядок рівносильний попередньому: корінь у них той самий.

3Де помиляються

Перемикай і порівнюй: зліва помилка, справа — як треба.

Звідси правило: переносячи доданок через знак «=», міняй його знак. Розкриваючи дужки, множ на кожен доданок. А ділити можна тільки на число, яке не нуль: якщо після зведення вийшло 0·x, корінь шукають не діленням, а питанням «чи правильна рівність».

5Перевір себе

Спершу розвʼяжи сам. Потім відкривай.

7x − 3 = 4x + 9
7x − 4x = 9 + 3, 3x = 12, x = 4. Один корінь. Перевірка: 7·4 − 3 = 25 і 4·4 + 9 = 25.
5(x + 1) = 5x + 5
5x + 5 = 5x + 5, 0·x = 0. Рівність правильна при будь-якому x: коренем є будь-яке число.
2x + 1 = 2x − 3
2x − 2x = −3 − 1, 0·x = −4. Нуль ніколи не дорівнює −4: коренів немає.
−3x = 12
Ділимо обидві частини на −3: x = −4. Знак кореня відʼємний, бо ділимо додатне на відʼємне.
0,2x − 1 = 2
0,2x = 3, x = 3 : 0,2 = 15. Один корінь.
Коротко:
Розкрий дужки, перенеси доданки з x вліво, числа вправо (міняючи знак), зведи подібні — вийде ax = b.
a ≠ 0 — один корінь: x = b : a.
a = 0, b = 0 — коренем є будь-яке число.
a = 0, b ≠ 0 — коренів немає.
Корінь перевіряй підстановкою в початкове рівняння.

Звідки правило переносу — «Терези»; чому перетворення не губить коренів — «Що саме не має змінитися».
