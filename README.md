# Математика по темах

Зібрані HTML-сторінки з поясненнями й шпаргалками з математики. Головне меню `index.html`, кожна сторінка лежить у теці своєї теми:

- `stepeni-i-loharyfmy/`: Ступені під капотом, Логарифми з нуля
- `droby/`: Спільний знаменник
- `rivniannia/`: Що саме не має змінитися (перетворення рівнянь), Терези
- `heometriia/`: Шпаргалка з трапеції

Сторінки статичні, збирати нічого не треба. Нова сторінка = тека `<тема>/<назва>/index.html` + картка в `index.html`.

Спільний вигляд у `assets/`: `site.css` (палітра light/dark, шрифти, фон-зошит, панель зверху) і `theme.js` (тема під ключем `theme`, подія `themechange` для сторінок, що перемальовуються). Нова сторінка підключає обидва файли в `<head>`, на початку `<body>` ставить `<nav class="site-bar">` з `.site-home` і `#site-theme`, а кольори бере тільки з токенів `site.css`.
